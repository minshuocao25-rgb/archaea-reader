# ARCHAEA · 古DNA与生物考古文献阅读台

这是一个可以直接打开的 **local-first 文献阅读台 MVP**，参照「边界之外」的暖白、低饱和蓝铜色视觉风格。v0.2 增加返回「边界之外」的入口；v0.3 增加整段翻译与词表；v0.4 增加原文分段与 PDF 页码批注；v0.5 合并为「原文对照阅读」（PDF 自动分页/分栏/分段、逐段译文与词汇、内联批注、扫描版 OCR）；v0.6 支持导入新的 PDF / DOCX 文献并直接进入对照阅读。

## 立即使用

- 浏览器直接打开 `index.html`。文件已内嵌第007—013期 JSON 归档，共 7期、16条历史论文记录。
- 左栏：按日归档、搜索与当前论文的边注。
- 中栏：「研究精读」展示结构化解读；「原文阅读」通过 OpenAlex **寻找合法开放获取 PDF**，或读取已合法取得的本机 PDF，并自动提取文字、分页、分栏、分段；「书目与核验」可在线检查 DOI 登记。
- 右栏：三组个人笔记、阅读状态、个人优先级、自动保存、手动保存历史版本。
- 研究精读中的选区可以点击「选段批注」加入边注。跨域 PDF 或出版社网页无法直接读取选区，可添加引文/页码作为手动边注。
- 右上角「导出 Markdown」只下载当前论文及其笔记、边注；「打印 / 保存为 PDF」使用浏览器打印对话框。右栏底部仍可导出完整 JSON 备份（含 `issues + notes + margins + revisions`）。「导入归档」支持每日 JSON 和已导出的备份；冲突期次保存成 `-v2`, `-v3`，旧版不覆盖。
- PDF 文件本身单独保存在**当前设备浏览器的 IndexedDB**，不包含在导出的 JSON 里。请另外备份 PDF。导入文献的正文与 DOCX 原文件同样只存 IndexedDB；JSON 备份只含元数据，换设备需重新导入文件。
- PDF：载入本机或开放获取 PDF 后，用 pdf.js 在浏览器内提取文字，自动分页、分栏、分段；每段显示**原文 + 译文 + 词汇**，点「＋ 批注」行内写批注即可进入左栏边注，定位自动为「PDF p.N ¶M」。扫描版自动转 OCR（tesseract.js + 英文模型，较慢）。
- 翻译设置：默认「自动（本地优先）」——优先 Chrome 内置翻译，失败转 Google / MyMemory；可切换「学术模型（本机 / 自建 API）」：支持 OpenAI 兼容接口、可选 Key、通用学术 / HY-MT 提示方式，目标段落结合标题、相邻正文和专业词表翻译；不发送私人笔记或批注。地址 / 模型 / 可选 Key 只存本机 `localStorage`，模型引擎失败不会转发至 Google 等其他服务。译文按段懒加载并缓存在本机，不写入归档，也不进入 JSON 备份。
- 「＋ 文献」或把 PDF / DOCX 拖入页面：解析后弹出元数据确认，导入为「IMPORT · 我的导入」条目，并**自动生成原文对照阅读**，无需粘贴。PDF 仍可在「查看原 PDF」中打开；DOCX 按纯文本段落提取（图片、表格不保留）。元数据与原文只存本机，DOCX 解析使用 mammoth.js。
- 无法直接解析的 PDF（跨域、扫描质量差）会保留原 PDF 预览，可下载后用「载入本机 PDF」重试，或把文字粘贴到「换一段原文」。
- v0.6.1：PDF 按跨栏区域及栏内正文顺序分段，过滤重复页眉页脚与参考文献；v0.6.2 将可识别的图片、矢量图表及图内标签裁成原图，随图注插入原页正文位置，图注不再混入正文翻译；保留正文中对图表的讨论。旧的 PDF 正文可点击「重新整理正文」应用新规则（需保留原 PDF），批注会按摘录匹配新位置，无法匹配的批注仍保留原定位。
- 中文段落显示「中文原文 · 无需翻译」，不进入翻译队列，也不发送给翻译接口。中英混排以段落主要语言判断。
- 左栏选择本机导入文献后可点「− 删除」，移除条目、原文件与解析正文。默认保留笔记、边注和历史版本及已删除条目的元数据（完整 JSON 备份的 `local-imports.removed_papers`）；确认框中可勾选同时删除。公开归档文献不提供此删除操作。

## 数据安全与限制

- 没有服务器：批注只保存在当前浏览器的 `localStorage`，上传的 PDF 保存在 IndexedDB。清理网站数据、换手机、换浏览器，可能导致丢失。**定期导出备份**。
- v0.2 的「边界之外」链接已加入 ARCHAEA 顶栏；反向入口需要修改「边界之外」站点源文件。当前无法从公开网址直接改写该站点，项目包附有 `BOUNDARY_LINK_INTEGRATION.md`，供 Codex 在其源项目中添加入口。
- HTML 静态站点不能自动将 ChatGPT 每日任务输出推送到网站。当前需要每天导入自动生成的 JSON，或后续添加独立后端/仓库更新工作流。
- 线上地址：<https://minshuocao25-rgb.github.io/archaea-reader/>（GitHub Pages 从 `main` 分支根目录发布）。没有云端同步或账号系统；私人批注仍只保存在当前浏览器。
- 浏览器优先读取本地已保存的归档（`localStorage`），而不是页面内嵌的初始数据。因此重新构建并部署后，已访问过本站的设备仍会显示旧归档；需要站内「导入归档」更新，或清理该站点数据后刷新。
- PDF 文本提取与 OCR 全部在浏览器本地完成，不上传 PDF；扫描版目前只带英文 OCR 模型，中文扫描件识别有限。图像裁切以图注、绘图范围和版面坐标判断，复杂跨栏、多面板、无图注图像仍可能有误；图片只存本机 IndexedDB，不上传。图片提取失败会显示提示。复杂多栏、公式、参考文献的阅读顺序仍是 Beta，可点「查看原 PDF」对照原文。
- 词汇简析来自内置参考词库 `data/lexicon.json`（专业词、CET4/CET6/IELTS 参考词与构词词素），难度标注为近似值；标为「未收录」的词只给构词线索，引用前请自行核对。使用在线翻译回退时，段落会发送给对应的第三方接口。
- OpenAlex 提供的免费全文线索仅是查找来源，无法保证每篇 DOI 有开放 PDF；有些出版社禁止站内嵌入，须外部打开。
- 网站中原有书目数据来自以前生成的日报，不代表网站已逐条重新核验；打开「书目与核验」可查询 DOI 登记进行部分检查。历史数据有重复推荐条目的风险。
- 早于2026-10-16的第001—006期，暂未拥有结构化 JSON，未迁入当前初始数据（可在未来导入）。

## 开发与部署

这是无构建依赖的纯静态版本：`index.html` 单文件嵌入全部 CSS、JS、公开归档与词汇库，适合 GitHub Pages、Cloudflare Pages、Netlify 等静态托管。服务端不需要 Node。`python build.py` 会把 `data/archive.json`、`data/lexicon.json` 注入 `base.html` 的四个占位符（`CSS_INJECT` / `LEXICON_INJECT` / `DATA_INJECT` / `JS_INJECT`）生成 `index.html`。PDF 解析、DOCX 解析与 OCR 依赖放在 `vendor/`（pdf.js、mammoth.js、tesseract.js 及英文语言包，Apache-2.0/BSD-2-Clause），只在需要时按需加载。

建议正式版后端：独立只读 `issues` 内容表 + 用户私有 `notes/margins/revisions` 表。账户登录应启用行级权限控制；防止跨账号泄漏私人注释。静态代码中不要放 API 密钥。

## 每日导入到已托管的静态网站

```bash
python import_issues.py adna-bioarch-2026-10-23.json
```

脚本会把新的期次追加至 `data/archive.json`，若该期内容发生改动则保存成 `-v2` 等新版本，生成新的 `index.html`，然后将变更提交到托管仓库即可更新公共阅读内容。注意：此流程只维护公共文献档案，不上传你的私人笔记。若需要跨设备共享私人笔记，仍必须增加经认证的云端数据库。

## 本机学术翻译

见 `LOCAL_TRANSLATION_PLAN.md`：推荐模型、下载量、许可证及安装后验收流程。当前网站只提供模型接口，未自带模型或运行服务。需先运行服务，在原文阅读的「翻译设置」选择学术模型，填入实际地址 / 模型名并「测试连接 / 试译」后保存。译文缓存按引擎、服务、模型、提示方式及上下文区分；中文正文直接保留。

### v0.6.2 阅读体验

文件来源与正文工具默认折叠；翻译设置位于正文上方；词汇可按需展开。导入确认期间防止重复点击，正文与原文件保存成功后才加入文献列表，失败保留导入确认框供重试。图片裁切仅保存在本机；旧 PDF 点击「正文工具 → 重新整理正文」以生成图片。图像裁切为启发式识别，复杂图表请对照原 PDF；模型服务尚需按安装方案单独启用，不能把网站接口测试视为翻译质量验证。

### v0.6.3 分段与信息识别

- 在合并文字行前识别窄栏间距；上标及首字下沉回到所属文字行，减少串栏、同位素符号丢失和短碎片。
- 正文在不跨越小节、图表、页码和栏位的前提下合并连续碎片。长段优先按句子拆分；单个长句按分句或词边界拆分。英文阅读单元上限约 1100 字符，中文约 520 字符；标题、完整的短段不强行拼接。
- PDF 导入优先使用与首页相符的内嵌标题、作者，再检查首页字号与位置；识别多行标题、作者名单，排除机构和小节。年份不再默认猜成当前年。候选信息仍需在导入确认框复核。
- 可在导入确认框点击「用 DOI 核对标题与作者」，向 Crossref 发送所填 DOI；确认论文匹配后填入登记信息，不代表全文或科学结论核验。失败不覆盖已填内容。
- 已导入 PDF 不自动重写正文和元数据；分段更新提示会引导使用「重新整理正文」，原摘录与无法匹配的新定位继续保留。该版本未安装模型。
