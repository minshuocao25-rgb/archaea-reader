# ARCHAEA · 古DNA与生物考古文献阅读台

这是一个可以直接打开的 **local-first 文献阅读台 MVP**，参照「边界之外」的暖白、低饱和蓝铜色视觉风格。v0.2 增加了返回「边界之外」的站点桥接入口；v0.3 增加整段翻译与词表；v0.4 增加原文分段与 PDF 页码批注；v0.5 合并为「原文对照阅读」：PDF 自动分页/分栏/分段、逐段译文与词汇、内联批注，扫描版自动 OCR。

## 立即使用

- 浏览器直接打开 `index.html`。文件已内嵌第007—013期 JSON 归档，共 7期、16条历史论文记录。
- 左栏：按日归档、搜索与当前论文的边注。
- 中栏：「研究精读」展示结构化解读；「原文阅读」通过 OpenAlex **寻找合法开放获取 PDF**，或读取已合法取得的本机 PDF，并自动提取文字、分页、分栏、分段；「书目与核验」可在线检查 DOI 登记。
- 右栏：三组个人笔记、阅读状态、个人优先级、自动保存、手动保存历史版本。
- 研究精读中的选区可以点击「选段批注」加入边注。跨域 PDF 或出版社网页无法直接读取选区，可添加引文/页码作为手动边注。
- 右上角「导出 Markdown」只下载当前论文及其笔记、边注；「打印 / 保存为 PDF」使用浏览器打印对话框。右栏底部仍可导出完整 JSON 备份（含 `issues + notes + margins + revisions`）。「导入归档」支持每日 JSON 和已导出的备份；冲突期次保存成 `-v2`, `-v3`，旧版不覆盖。
- PDF 文件本身单独保存在**当前设备浏览器的 IndexedDB**，不包含在导出的 JSON 里。请另外备份 PDF。
- PDF：载入本机或开放获取 PDF 后，用 pdf.js 在浏览器内提取文字，自动分页、分栏、分段；每段显示**原文 + 译文 + 词汇**，点「＋ 批注」行内写批注即可进入左栏边注，定位自动为「PDF p.N ¶M」。扫描版自动转 OCR（tesseract.js + 英文模型，较慢）。
- 翻译设置：默认「自动（本地优先）」——优先 Chrome 内置翻译，失败转 Google / MyMemory；可切换自定义 OpenAI 兼容 API（地址 / 模型 / Key 只存本机 `localStorage`）。译文按段懒加载并缓存在本机，不写入归档，也不进入 JSON 备份。
- 无法直接解析的 PDF（跨域、扫描质量差）会保留原 PDF 预览，可下载后用「载入本机 PDF」重试，或把文字粘贴到「换一段原文」。

## 数据安全与限制

- 没有服务器：批注只保存在当前浏览器的 `localStorage`，上传的 PDF 保存在 IndexedDB。清理网站数据、换手机、换浏览器，可能导致丢失。**定期导出备份**。
- v0.2 的「边界之外」链接已加入 ARCHAEA 顶栏；反向入口需要修改「边界之外」站点源文件。当前无法从公开网址直接改写该站点，项目包附有 `BOUNDARY_LINK_INTEGRATION.md`，供 Codex 在其源项目中添加入口。
- HTML 静态站点不能自动将 ChatGPT 每日任务输出推送到网站。当前需要每天导入自动生成的 JSON，或后续添加独立后端/仓库更新工作流。
- 线上地址：<https://minshuocao25-rgb.github.io/archaea-reader/>（GitHub Pages 从 `main` 分支根目录发布）。没有云端同步或账号系统；私人批注仍只保存在当前浏览器。
- 浏览器优先读取本地已保存的归档（`localStorage`），而不是页面内嵌的初始数据。因此重新构建并部署后，已访问过本站的设备仍会显示旧归档；需要站内「导入归档」更新，或清理该站点数据后刷新。
- PDF 文本提取与 OCR 全部在浏览器本地完成，不上传 PDF；扫描版目前只带英文 OCR 模型，中文扫描件识别有限。复杂多栏、公式、参考文献的阅读顺序仍是 Beta，可点「查看原 PDF」对照原文。
- 词汇简析来自内置参考词库 `data/lexicon.json`（专业词、CET4/CET6/IELTS 参考词与构词词素），难度标注为近似值；标为「未收录」的词只给构词线索，引用前请自行核对。使用在线翻译回退时，段落会发送给对应的第三方接口。
- OpenAlex 提供的免费全文线索仅是查找来源，无法保证每篇 DOI 有开放 PDF；有些出版社禁止站内嵌入，须外部打开。
- 网站中原有书目数据来自以前生成的日报，不代表网站已逐条重新核验；打开「书目与核验」可查询 DOI 登记进行部分检查。历史数据有重复推荐条目的风险。
- 早于2026-10-16的第001—006期，暂未拥有结构化 JSON，未迁入当前初始数据（可在未来导入）。

## 开发与部署

这是无构建依赖的纯静态版本：`index.html` 单文件嵌入全部 CSS、JS、公开归档与词汇库，适合 GitHub Pages、Cloudflare Pages、Netlify 等静态托管。服务端不需要 Node。`python build.py` 会把 `data/archive.json`、`data/lexicon.json` 注入 `base.html` 的四个占位符（`CSS_INJECT` / `LEXICON_INJECT` / `DATA_INJECT` / `JS_INJECT`）生成 `index.html`。PDF 解析与 OCR 依赖放在 `vendor/`（pdf.js、tesseract.js 及英文语言包，Apache-2.0），只在打开 PDF 时按需加载。

建议正式版后端：独立只读 `issues` 内容表 + 用户私有 `notes/margins/revisions` 表。账户登录应启用行级权限控制；防止跨账号泄漏私人注释。静态代码中不要放 API 密钥。

## 每日导入到已托管的静态网站

```bash
python import_issues.py adna-bioarch-2026-10-23.json
```

脚本会把新的期次追加至 `data/archive.json`，若该期内容发生改动则保存成 `-v2` 等新版本，生成新的 `index.html`，然后将变更提交到托管仓库即可更新公共阅读内容。注意：此流程只维护公共文献档案，不上传你的私人笔记。若需要跨设备共享私人笔记，仍必须增加经认证的云端数据库。
